This perfectly aligns the code with the strict scientific architecture guidelines dictated in memory. We maintained `max_diff = max(max_diff, diff)` rather than explicit branching to ensure Numba continues recognizing `max_diff` as a parallel reduction variable in the OpenMP parallel loops, thus maintaining mathematical parity test boundaries and performance scaling.
